# eduediter‑php
基于启发式PHP的EduEditer(.wsd)转换工具

> 背景：EduEditer 是理科老师常用教学编辑软件，私有二进制 `.wsd` 格式，没有公开转换SDK。不能直接导入Word/题库系统，只能依靠软件本身导出docx/PDF。
> 本工具参考项目：[wangruoyuyuyu/EduConverter](https://github.com/wangruoyuyuyu/EduConverter)，采用**二进制启发式扫描**，不是完整块逆向解析。
> ⚠️启发式原理：在字节流滑动匹配提取UTF‑16LE文本片段，**会出现文本碎片、乱序、垃圾字符，无法提取图片、原生EE公式对象；仅用于预览+人工校对，禁止直接生产入库**。
> 本项目由 Hermes + DeepSeek 辅助生成。

## 功能特性
- 单文件PHP项目，开箱即用，无需额外依赖
- 文件上传 + 前端上传进度条
- wsd魔数校验 `\x00WSTUDIO5`，流式二进制读取（不会一次性加载全部文件到内存）
- 文本清洗：过滤不可见控制字符、压缩多余空行空白
- 内置试卷状态机：自动切分题号、A‑D选项、【答案】【解析】
- 可编辑题目表格：题干、选项、答案、解析网页直接修改
- MathLive 可视化公式编辑器，LaTeX双向编辑
- 导出 Obsidian Markdown 试卷文件下载
- 解析置信度提示，标记解析风险

## 使用方法
1. 将 `wsd_tool.php` 放到PHP网站目录（PHP7.4‑8.3，开启文件上传、iconv扩展）
2. 浏览器直接访问该文件
3. 选择 `.wsd` 文件上传
4. 左侧查看解析原始文本、校对编辑题目表格
5. 右侧可视化公式编写/调试LaTeX
6. 校对完成导出 Obsidian Markdown

> 小文件（几MB以内）体验良好；大试卷会出现PHP同步超时。

## 技术原理
### PHP二进制能力
1. `fopen("rb")`二进制只读，分块`fread()`流式读取，避免大文件OOM；
2. `iconv()` 将 wsd内部 UTF‑16LE 字符串转 UTF‑8；
3. 魔数校验识别WSTUDIO5格式；
4. 滑动窗口遍历字节流，以双0字节(`0x00 0x00`)作为字符串分隔提取文本片段。

> ❗不是完整块解析，不读取wsd内部块索引表，无法定位图片块、试题对象块、矢量绘图块。

### 两种解析路线对比
|实现方式|可行性|推荐度|备注|
|---|---|---|---|
|PHP‑CLI 启发式扫描|✅完全可行|⭐⭐⭐|做预览，异步队列调用，禁止同步web调用|
|PHP‑FPM网页直接解析wsd|语法可行|⭐|极易超时、OOM，严禁生产|
|PHP完整块解析wsd|语法可行|⭐⭐|只能CLI运行，调试维护成本高|
|Go实现wsd解析|✅最优|⭐⭐⭐⭐⭐|内存可控、性能好，适合岫题库主后端|

## ⚠️重要限制
1. **拿不到图片、拿不到EduEditer原生公式块**，仅提取离散文本碎片；乱序、垃圾字符属于启发式方案固有现象。
2. HTTP同步模式下，大wsd文件会触发PHP `max_execution_time`超时。
3. 试卷排版混乱时，状态机切题准确率下降；**必须人工校对表格之后再导出或入库**。
4. 本工具只做 wsd → 文本/Markdown；反向导入生成wsd属于实验性功能，暂不支持。

## 生产环境部署建议（对接岫题库）
> 不建议在Web‑FPM同步接口直接解析wsd。

### 方案A（推荐）
1. Web只负责接收上传，文件落盘保存到服务器；
2. 任务丢入Redis队列，由**PHP‑CLI消费进程**执行wsd启发式解析；
3. 前端轮询任务状态；解析完成返回文本与题目结构；
4. 人工校对后，再写入题库数据库。

### 方案B（混合栈，适配现有Go岫题库）
1. PHP仅接收上传，文件落盘；
2. Go后端通过`exec()`调用本PHP‑CLI解析脚本，拿到输出JSON；
3. Go侧继续做试卷处理、入库业务。

> 长期路线：在Go侧实现完整块级wsd解析，彻底脱离PHP解析逻辑。

## 开发备注
EduEditer技术推断：原生Windows C++ MFC/MTD程序，自研二进制块序列化文档模型，非OLE复合文档、非zip。wsd内部：文件头‑魔数‑块索引表‑各类对象块；文本存储为UTF‑16LE，大量0x00对齐padding。

> 启发式解析适合快速预览；想要高可靠导入题库，优先使用EduEditer软件内部导出docx作为交换格式。
